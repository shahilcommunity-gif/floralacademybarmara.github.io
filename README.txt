# Floral Academy Barmara — Free Website

Files:
- index.html — main website
- style.css — design
- script.js — classes and study-material interface
- assets/school.jpg — school photo supplied by the school representative

## Free publishing with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository named `floralacademybarmara.github.io`.
3. Upload all files/folders from this package.
4. Open Settings → Pages.
5. Choose “Deploy from a branch”, select `main` and `/root`, then Save.
6. Your free website will appear at:
   https://floralacademybarmara.github.io/

## Adding PDFs
Create a folder named `materials`, upload PDFs there, then change the links in `script.js`.
